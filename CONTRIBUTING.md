# Contributing

Issues and pull requests are welcome.

- Setup, build and testing: see [DEVELOPING.md](DEVELOPING.md).
- Keep the principles in the [README](README.md): offline, no tracking, FOSS dependencies only.
- Run `./gradlew spotlessApply assembleDebug testDebugUnitTest lintDebug` before opening a PR.
- Use American English in strings and docs.

By contributing you agree your work is licensed under Apache-2.0.
